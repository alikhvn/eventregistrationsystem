# Event Registration System — Project Requirements

## Жобаның мақсаты
Event Registration System — іс-шараларға (семинар, конференция, митап және т.б.)
қатысушыларды тіркеуді автоматтандыруға арналған веб-қосымша. Жүйе әкімшіге
іс-шараларды тізімде ұстауға, ал қатысушыларға қолжетімді орын санына қарай
онлайн тіркелуге мүмкіндік береді.

## Пайдаланушылар
- **Қатысушы (Participant)** — іс-шаралар тізімін көреді және тіркеу формасы
  арқылы өзін-өзі тіркейді.
- **Ұйымдастырушы (Organizer / Admin)** — іс-шараларды, олардың сыйымдылығын
  және тіркелген қатысушылар тізімін қадағалайды.

## Функционалдық талаптар
1. Жүйе қолданушыға қолжетімді іс-шаралар тізімін (атауы, күні, бос орын саны)
   көрсетуі керек.
2. Жүйе қатысушыны аты-жөні мен email арқылы таңдалған іс-шараға тіркей алуы
   керек.
3. Жүйе енгізілген деректерді тексеруі керек (аты кемінде 2 таңба, email
   дұрыс форматта болуы тиіс).
4. Жүйе бір email-дың бір іс-шараға қайта тіркелуіне жол бермеуі керек.
5. Жүйе іс-шараның сыйымдылығы толғанда жаңа тіркеуге тыйым салуы керек
   («FULL» күйі).
6. Жүйе әр іс-шара үшін тіркелген қатысушылар тізімін нақты уақытта
   (беттегі жаңартудан кейін) көрсетуі керек.

## Шектеулер
- Деректер SQLite базасында (`src/event_registration.db`) сақталады, сервер
  қайта іске қосылғанда жоғалмайды.
- Авторизация/аутентификация осы кезеңде қарастырылмаған, келесі
  зертханалық жұмыстарда қосылады.
